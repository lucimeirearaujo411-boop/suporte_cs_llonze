# Case 2 — Falha de Acesso por Credenciais Expiradas

## 1. Contexto

Este caso simula um atendimento de suporte em que um usuário não consegue acessar uma aplicação web utilizada em sua rotina profissional.

O objetivo é demonstrar uma abordagem estruturada para investigação, diagnóstico, orientação ao usuário e resolução do incidente.

## 2. Problema relatado

O usuário informa que não consegue acessar o sistema utilizando suas credenciais habituais.

### Relato do usuário

> "Estou tentando entrar no sistema, mas minha senha não está funcionando. Já tentei algumas vezes e continuo sem acesso."

## 3. Impacto

A impossibilidade de acesso impede o usuário de utilizar as funcionalidades necessárias para realizar suas atividades.

Por isso, o atendimento deve buscar uma solução rápida, sem deixar de validar a causa do problema.

## 4. Investigação inicial

Antes de realizar qualquer alteração, são coletadas informações para entender o cenário.

### Perguntas realizadas

- Qual mensagem de erro aparece ao tentar acessar?
- O usuário consegue acessar outros sistemas com as mesmas credenciais?
- A senha funcionava anteriormente?
- Quando o problema começou?
- Outros usuários estão conseguindo acessar normalmente?
- Houve alguma alteração recente na conta?

## 5. Hipóteses

Com base nas informações coletadas, algumas possibilidades são consideradas:

1. Senha expirada;
2. Credenciais digitadas incorretamente;
3. Conta bloqueada após tentativas consecutivas;
4. Problema específico no navegador;
5. Indisponibilidade temporária do sistema de autenticação.

## 6. Diagnóstico

Após a coleta das informações, é identificado que a senha do usuário está expirada.

Nesse cenário, não é necessário realizar alterações indiscriminadas na conta. O procedimento adequado é orientar o usuário sobre a redefinição da senha conforme o processo estabelecido pela empresa.

## 7. Orientação ao usuário

O usuário recebe instruções claras para realizar a redefinição:

1. Acessar a página de login;
2. Selecionar a opção de recuperação ou redefinição de senha;
3. Confirmar sua identidade conforme o procedimento de segurança;
4. Criar uma nova senha seguindo os requisitos definidos;
5. Realizar um novo acesso ao sistema.

Durante o atendimento, nenhuma senha é solicitada ou registrada pelo suporte.

## 8. Validação da solução

Após a redefinição, o usuário realiza uma nova tentativa de acesso.

O atendimento é considerado solucionado somente após a confirmação de que:

- O login foi realizado com sucesso;
- O sistema está funcionando normalmente;
- O usuário consegue utilizar a funcionalidade necessária.

## 9. Registro do atendimento

| Item | Informação |
|---|---|
| Tipo | Suporte técnico |
| Categoria | Acesso e autenticação |
| Prioridade | Média |
| Canal | Atendimento ao usuário |
| Causa identificada | Senha expirada |
| Ação realizada | Orientação para redefinição de senha |
| Status | Resolvido |
| Resultado | Acesso restabelecido |

## 10. Comunicação com o usuário

Uma comunicação adequada durante o atendimento poderia ser:

> "Identifiquei que sua senha está expirada. Vou te orientar pelo processo de redefinição para que você consiga recuperar o acesso com segurança. Depois que concluir, me confirme para validarmos juntos se o sistema voltou a funcionar normalmente."

## 11. Boas práticas aplicadas

- Escuta ativa;
- Investigação estruturada;
- Comunicação clara;
- Proteção das credenciais do usuário;
- Orientação objetiva;
- Registro do atendimento;
- Validação da solução;
- Foco na experiência do usuário.

## 12. Prevenção

Além de solucionar o incidente, é importante orientar o usuário sobre o prazo de validade da senha e os procedimentos disponíveis para recuperação de acesso.

A documentação desse tipo de ocorrência também pode ajudar a identificar padrões e reduzir chamados recorrentes.

Este caso demonstra competências relacionadas a:

- Suporte técnico;
- Investigação de incidentes;
- Diagnóstico de problemas de acesso;
- Atendimento ao usuário;
- Comunicação clara;
- Segurança no atendimento;
- Documentação;
- Resolução de problemas;
- Customer Success.
